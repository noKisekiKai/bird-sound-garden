# 小鳥悄悄話 · 聲音小森林

[開啟遊戲](https://nokisekikai.github.io/bird-sound-garden/)

按「開始遊戲」才會進入遊戲，每輪 20 秒，咪高峰成功啟動後才開始倒數。可隨時把「全部飛走的分貝」上限設為 40–120（預設 100）。35 估算分貝以下，24 隻小鳥全部留下；35 分貝至所設上限之間，飛走數目按比例線性增加（每次一隻）；達到上限才全部飛走。音量降低時，小鳥按比例飛回。調節上限不會重設 20 秒倒數。倒數結束後自動停止收音，按「再玩一輪」開始新一輪。

## 使用方法

1. iPad 請用 Safari，電腦請用 Chrome、Edge 或 Safari，直接開啟上方 HTTPS 遊戲網址。
2. 按「開始遊戲」，並允許網站使用咪高峰；每輪 20 秒。
3. 輕聲說話，觀察即時音量和小鳥的反應；毋須喊叫。
4. 未有咪高峰時，先勾選「示範模式」，再按「開始遊戲」；開始後可拖動音量滑桿。

若找不到咪高峰，請檢查裝置、瀏覽器權限及作業系統的咪高峰存取設定。學校管理的裝置可能需要管理員開放權限。

## 讀數及私隱

讀數由咪高峰訊號換算為估算分貝，並非專業聲級計或 dBA；不同裝置可能有明顯差異。遊戲提供單點校準功能。

音訊在瀏覽器內即時分析，不錄音、不上傳。校準數值僅儲存在裝置的瀏覽器。

## 檔案

`index.html` 為包含所有程式和圖像的獨立網頁，毋須安裝套件或後端伺服器。
